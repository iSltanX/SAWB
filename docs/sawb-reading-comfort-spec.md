## 1. القرار المنتجّي النهائي

**النطاق المعتمد (ولا شيء غيره):**

- ميزة واحدة اسمها **«راحة القراءة»** تحسّن **طباعة الكتل المصنّفة عربية/RTL** في
  **النصوص المعروضة**، عبر **حجم الخط** و**تباعد الأسطر** فقط.
- الحجم والتباعد **قيمتان عامّتان على مستوى الإضافة** (لا تخصيص قيم لكل موقع).
- **حالة تفعيل/تعطيل** الميزة **يجوز أن تكون خاصة بكل موقع**، بينما القيم تبقى عامة.
- الميزة **مطفأة افتراضيًا**؛ عند التفعيل تستخدم قيمًا ابتدائية معتدلة ضمن نطاقات آمنة،
  تُثبَّت نهائيًا بعد الاختبار الحي.
- الحجم والتباعد يظهران في **صفحة options فقط**؛ الـ **popup يحمل مفتاحًا سريعًا واحدًا**
  لتفعيل/تعطيل الميزة للموقع الحالي.
- **إدارة المواقع المعطّلة** تتم من صفحة options باستخدام `SitePref` والبيانات القائمة.
- **«راحة القراءة» طبقة فوق «النصوص المعروضة»:** تفعيلها الفعّال يشترط `display=true`؛
  حين `display=false` لا طباعة إطلاقًا (لا مسار طباعة مستقل).

**الحدود غير القابلة للتجاوز (موانع مبدئية):**

1. **لا مساس بالنص الإنجليزي** — الطباعة تُطبَّق على الكتل المصنّفة RTL حصرًا.
2. **لا مساس بالكود ولا حقول الإدخال** — تُستبعَد بالحُرّاس القائمة.
3. **لا تغيير لمحتوى النص** — تُكتب خصائص `font-size`/`line-height` فقط، وتُستعاد بدقة.
4. **لا خطوط في هذا الإصدار إطلاقًا** — لا `displayFont`، لا `@font-face` للمحتوى، لا
   `web_accessible_resources`، **ولا تبدأ تجربة Font Feasibility Spike ضمن هذه المرحلة**.
5. **لا وضع قراءة، لا مواقع جديدة، ولا إعادة بناء للمشروع.**
6. **لا توسيع صلاحيات** — `permissions` يبقى `["storage"]`.
7. **لا هبوط عن خط الأساس** — ‏219 اختبارًا تبقى ناجحة، والبناء يبقى ناجحًا.
8. **لا سمة DOM جديدة** — الـ WeakMap القائمة هي مصدر حالة الطباعة (لا `data-sawb-rc`).
9. **لا ملف نواة جديد للطباعة** — كل دواله داخل `apply.ts`.

## 2. نموذج الإعدادات النهائي

المبدأ: **حقول إضافية بحتة**، تعتمد على الدمج القائم `{...DEFAULT_SETTINGS, ...stored}`
في [`storage.ts`](../src/platform/storage.ts) فلا تحتاج هجرة. **لا حقل خطوط.**

### 2.1 الحقول الجديدة (TypeScript)

في [`src/platform/types.ts`](../src/platform/types.ts):

```ts
// ── Settings (عامّة على مستوى الإضافة) ──────────────────────────────
export interface Settings {
  enabled: boolean;
  defaultMode: Mode;
  applyToFields: boolean;
  applyToDisplay: boolean;
  showIndicator: boolean;
  theme: Theme;

  // ‏«راحة القراءة» — جديد
  readingComfort: boolean;   // التفعيل الافتراضي العام للميزة
  rcFontScale: number;       // مضاعف حجم الخط العام (نسبة، لا px مطلق)
  rcLineHeight: number;      // تباعد الأسطر العام (معامل بلا وحدة)
}

// ── SitePref (لكل موقع — الحالة فقط، لا القيم) ───────────────────────
export interface SitePref {
  mode?: Mode;
  fields?: boolean;
  display?: boolean;
  disabled?: boolean;

  // تفعيل/تعطيل «راحة القراءة» لهذا الموقع فقط (تجاوز للحالة العامة).
  // لا يوجد حجم/تباعد لكل موقع — القيم عامة دائمًا.
  readingComfort?: boolean;

  savedAt: number;
}

// ── TempOverride (لكل تبويب، في الذاكرة، غير محفوظ) ──────────────────
export interface TempOverride {
  mode?: Mode;
  fields?: boolean;
  display?: boolean;
  disabled?: boolean;

  readingComfort?: boolean;  // مفتاح popup السريع قبل الحفظ
}

// ── EffectiveConfig (ناتج الدمج الذي تعمل به الصفحة) ─────────────────
export interface EffectiveConfig {
  enabled: boolean;
  mode: Mode;
  fields: boolean;
  display: boolean;
  showIndicator: boolean;

  readingComfort: boolean;   // هل الطباعة فعّالة لهذه الصفحة
  fontScale: number;         // مُمرَّر من القيمة العامة (rcFontScale)
  lineHeight: number;        // مُمرَّر من القيمة العامة (rcLineHeight)
}
```

### 2.2 القيم الافتراضية

في `DEFAULT_SETTINGS`:

```ts
export const DEFAULT_SETTINGS: Settings = {
  enabled: true,
  defaultMode: 'auto',
  applyToFields: true,
  applyToDisplay: false,
  showIndicator: true,
  theme: 'system',

  readingComfort: false,   // مطفأة افتراضيًا (قرار 4)
  rcFontScale: 1.08,       // قيمة بدء للاختبار الحي (القسم 7)
  rcLineHeight: 1.8,       // قيمة بدء للاختبار الحي (القسم 7)
};
```

> ملاحظة: `readingComfort=false` يعني أن الميزة لا تُطبِّق شيئًا حتى يفعّلها المستخدم؛
> ومتى فُعّلت، تسري القيم الابتدائية المعتدلة (‏1.08 / ‏1.8) فورًا — وهذا يحقّق قرار 5.

### 2.3 أين يوضع كل حقل

| الحقل | الموضع | السبب |
|---|---|---|
| `readingComfort` (التفعيل العام) | `Settings` | افتراض عام يُطبَّق على المواقع بلا تفضيل |
| `rcFontScale`, `rcLineHeight` | `Settings` **فقط** | القيم **عامة** (قرار 3) — لا مكان لها في `SitePref` |
| `readingComfort?` (لكل موقع) | `SitePref` | حالة التفعيل يجوز أن تكون لكل موقع (قرار 8) |
| `readingComfort?` (مؤقت) | `TempOverride` | مفتاح popup السريع قبل الحفظ |
| `readingComfort`, `fontScale`, `lineHeight` | `EffectiveConfig` | ما تعمل به الصفحة فعليًا |

### 2.4 أولوية الدمج في `resolveEffectiveConfig`

توسيع الدالة القائمة في [`types.ts:67`](../src/platform/types.ts) دون تغيير آليتها:

```ts
export function resolveEffectiveConfig(settings, site, temp, opts = {}): EffectiveConfig {
  const disabled = (site?.disabled ?? false) || (temp?.disabled ?? false);
  const displayDefault = opts.genericSite ? false : settings.applyToDisplay;
  const rcDefault      = opts.genericSite ? false : settings.readingComfort; // أمان الوضع العام

  const display = temp?.display ?? site?.display ?? displayDefault;
  // الطلب: temp ← site ← global (نفس أولوية display)، مع أمان الوضع العام.
  const rcRequested = temp?.readingComfort ?? site?.readingComfort ?? rcDefault;

  return {
    enabled: settings.enabled && !disabled,
    mode:    temp?.mode    ?? site?.mode    ?? settings.defaultMode,
    fields:  temp?.fields  ?? site?.fields  ?? settings.applyToFields,
    display,
    showIndicator: settings.showIndicator,

    // «راحة القراءة» تتطلّب display=true: تنبني على معالجة النصوص المعروضة.
    // إن كان display=false فالطباعة مطفأة مهما كان الطلب.
    readingComfort: display && rcRequested,
    // القيم عامة دائمًا (لا temp ولا site)
    fontScale: settings.rcFontScale,
    lineHeight: settings.rcLineHeight,
  };
}
```

- **الاشتراط الحاسم:** `readingComfort` الفعّال = `display && rcRequested`. **الطباعة
  لا تعمل مع `display=false`** — الميزة طبقة فوق معالجة النصوص المعروضة، لا مسار مستقل.
- **أولوية الطلب:** `rcRequested = temp?.readingComfort ?? site?.readingComfort ?? (genericSite ? false : settings.readingComfort)`.
- **القيم عامة:** `fontScale`/`lineHeight` تُقرأ من `settings` مباشرةً؛ **لا يجوز** قراءتها
  من `site` أو `temp` (قرار 3).
- **أمان الوضع العام:** على مواقع المحوّل العام تبقى الميزة مطفأة إلا بتفعيل صريح
  (site/temp)، تمامًا كسلوك `display` — ولأنها تشترط `display`، فالتفعيل على موقع عام
  يستلزم تفعيل `display` هناك أيضًا.

### 2.5 سلوك البيانات القديمة و`schemaVersion`

- **[حقيقة]** `getSettings()` يعيد `{...DEFAULT_SETTINGS, ...stored}` — فبيانات v1.1.0
  التي لا تحوي `readingComfort`/`rcFontScale`/`rcLineHeight` تُملأ بالقيم الافتراضية
  تلقائيًا.
- **[حقيقة]** `SitePref.readingComfort` اختياري؛ غيابه في المواقع القديمة = `undefined`
  → يرث الحالة العامة (‏false).
- **القرار:** **لا رفع لـ `SCHEMA_VERSION`** (يبقى ‏1) و**لا حاجة لمنطق migration فعلي**؛
  الدمج الإضافي يغطّي كل الحالات. (يبقى هيكل `initStorage()` كما هو.)

**لا `displayFont` ولا أي حقل خطوط في أي طبقة.**

## 3. دلالة التفعيل بدقة

يجب التمييز الحادّ بين أربع حالات لئلا تختلط:

| المفهوم | مصدره | أثره على `EffectiveConfig` | ما الذي يُطبَّق/يُستعاد |
|---|---|---|---|
| **1) تعطيل صَوْب كاملًا على موقع** | `SitePref.disabled=true` (زر «تعطيل الموقع» — أيقونة الحظر) | `enabled=false` | المحرّك **يتوقف** (`engine.stop()`): يُستعاد الاتجاه **والطباعة** معًا؛ لا شيء يعمل |
| **2) تعطيل معالجة النصوص المعروضة** | `display=false` (مفتاح «النصوص المعروضة») | `display=false` → **`readingComfort` يُجبَر على false** | لا اتجاه عرض؛ **ولا طباعة** (لأنها تشترط `display`)؛ الحقول تعمل |
| **3) تعطيل «راحة القراءة» فقط على موقع** | `SitePref/Temp.readingComfort=false` (المفتاح السريع في popup) | `readingComfort=false` مع بقاء `display` | **الطباعة تُزال فقط**؛ الاتجاه (حقول + عرض) يبقى يعمل كما هو |
| **4) المفتاح العام لراحة القراءة** | `Settings.readingComfort` (options) | الافتراض عند غياب تجاوز الموقع/التبويب | يحدّد السلوك الافتراضي لكل المواقع بلا تفضيل صريح |

**ملاحظة تصميمية حاسمة:** «راحة القراءة» **طبقة فوق** «النصوص المعروضة»، لا مسار مستقل.
`readingComfort` الفعّال يشترط `display=true`. تبقى الحالتان **متمايزتين** كعمليتين:
«تعطيل النصوص المعروضة» (‏2) يُلغي الاتجاه **والطباعة** معًا (الطباعة تسقط تبعًا)؛
و«تعطيل راحة القراءة فقط» (‏3) يُلغي **الطباعة وحدها** ويُبقي الاتجاه. أي التعطيل في
اتجاه واحد: `display` شرط للطباعة، لكن الطباعة ليست شرطًا للاتجاه.

### 3.1 جدول الحقيقة لـ `EffectiveConfig`

بافتراض `Settings.enabled=true` و`fields=true` و`mode=auto` (ما لم يُذكر خلافه).
`RC (مطلوب)` = الطلب قبل الاشتراط؛ `RC (فعّال)` = `display && RC(مطلوب)`:

| # | `site.disabled` | `display` (فعّال) | `RC (مطلوب)` | `RC (فعّال)` | `enabled` | سلوك المحرّك على كتل العرض |
|---|:---:|:---:|:---:|:---:|:---:|---|
| A | false | false | false | false | **true** | حقول فقط؛ لا اتجاه عرض؛ **لا طباعة** |
| A′ | false | false | **true** | **false** *(مُجبَر: RC يشترط display)* | **true** | حقول فقط؛ لا اتجاه عرض؛ **لا طباعة** |
| B | false | **true** | false | false | **true** | حقول + **اتجاه عرض**؛ **لا طباعة** |
| D | false | **true** | **true** | **true** | **true** | حقول + **اتجاه عرض + طباعة على كتل RTL** |
| E | **true** | — | — | — | **false** | `engine.stop()` — يُستعاد كل شيء (اتجاه + طباعة)؛ لا شيء يعمل |

> **الحالة C محذوفة:** لم تعد ثمة تركيبة «`display=false` + طباعة تعمل». حين `display=false`
> يُجبَر `RC (فعّال)` على `false` (الصف A′)، فلا مسار طباعة مستقل عن معالجة العرض.

**قراءات مهمة من الجدول:**

- الطباعة لا توجد إلا في **D** (الحالة الوحيدة التي `display` و`RC` فيها فعّالان معًا).
- الفرق بين **B** و**D**: **B** اتجاه بلا طباعة، **D** اتجاه + طباعة. المفتاح السريع
  في popup ينقل بين B وD (يقلب طلب `readingComfort`) — **شرط أن يكون `display` فعّالًا**.
- **A′** توضّح الاشتراط: طلب راحة القراءة مع `display=false` لا يُنتج طباعة.
- **E** هو التعطيل الكامل — لا يُخلَط مع **B** (تعطيل جزئي). E يوقف المحرّك؛ B يُبقيه
  يعمل بجزء من الوظائف.

## 4. اختيار نهج تطبيق الطباعة

المقارنة بين النهجين المطروحين (النهج الثالث «CSS variables على جذر العرض» **مرفوض
نهائيًا** بقرار سابق، ولا يُستخدم):

| المعيار | **(أ) أنماط سطرية على الكتل RTL** | **(ب) وسم الكتل RTL + ورقة أنماط معزولة** |
|---|---|---|
| الاستعادة الدقيقة | لقطة `OriginalState` نفسها المستخدمة لـ `dir`/`unicode-bidi` — آلية مُثبَتة | إزالة السمة فقط، لكن الورقة تحتاج `!important` لتغلب أنماط الموقع السطرية → أكثر تدخّلًا |
| idempotence | مقارنة `style.fontSize === desired` قبل الكتابة — نفس نمط `setDir` | تحتاج تتبّع «هل السمة موجودة» + مزامنة الورقة |
| MutationObserver | يُلتقَط عبر `onBatch` القائم، بلا مراقبة إضافية | كذلك، لكن الورقة عنصر عالمي إضافي يجب حمايته من إعادة التصيير |
| عدد كتابات DOM | كتابة سطرية لكل كتلة RTL (تُحدَّث بـ idempotence) | سمة لكل كتلة RTL + كتابة ورقة واحدة عند تغيير القيم |
| تجنّب التسرّب | صفر كتابة على الكتل الإنجليزية (لا تُصنَّف RTL) | مماثل |
| سهولة الاختبار | **مباشر في jsdom** (`el.style.fontSize`) | **أصعب** — jsdom لا يحسب تعاقب الأنماط من ورقة محقونة بموثوقية |
| توافق `hostWonFight` | يماثل مسار `dir` تمامًا؛ أي توسعة استسلام مستقبلية موحّدة | السمة قد يعيد المضيف ضبطها؛ مسار مختلف عن dir |
| تغيير الإعدادات فوريًا | إعادة تمريرة `onBatch`/`applyAll` تُحدِّث الأنماط السطرية (idempotent) | تحديث نص الورقة (كتابة واحدة) — أخفّ نظريًّا لكنه يضيف طبقة |
| حقن ورقة أنماط | **لا** — يوافق مبدأ المشروع «no stylesheet injection» ([`indicator.ts`](../src/content/indicator.ts)) | **نعم** — يخالف المبدأ ويضيف بصمة عالمية |

### القرار: **النهج (أ) — أنماط سطرية على الكتل المصنّفة RTL.**

**التبرير:**

1. **امتداد مباشر لآلية مُثبَتة:** [`apply.ts`](../src/core/apply.ts) يكتب أصلًا
   `unicode-bidi`/`direction` سطريًّا مع لقطة/استعادة (`isolateLtr`, `restoreElement`)؛
   الطباعة تعيد استخدام النمط ذاته بلا سطح جديد.
2. **استعادة دقيقة بنفس الانضباط:** توسيع `OriginalState` يلتقط `font-size`/`line-height`
   الأصليين، والاستعادة تحذف الخاصية أو تعيد القيمة الأصلية — لا دلالة استعادة جديدة.
3. **بلا حقن ورقة أنماط:** يوافق قرار المشروع المتعمّد بعدم حقن Stylesheet عام (المؤشر
   يستخدم أنماطًا سطرية لهذا السبب).
4. **قابلية اختبار مباشرة:** الأنماط السطرية تُقرأ في jsdom مباشرةً؛ النهج (ب) لا
   يُحسَب تعاقبه في jsdom بموثوقية.
5. **idempotence بنمط `setDir` نفسه:** الكتابة فقط عند اختلاف القيمة.
6. **بلا `!important`:** لا حاجة لتصعيد يخالف أنماط الموقع كما يحتاج النهج (ب).

**قيد صريح:** ممنوع استخدام CSS variables على جذر العرض أو أي وراثة من الجذر.

## 5. دورة حياة الكتلة (خطوة بخطوة)

تُطبَّق داخل التمريرة القائمة على كتل العرض الورقية (`leafBlocks(root)` في
[`apply.ts`](../src/core/apply.ts))، بحيث لا تُضاف تمريرة/مراقبة ثانية. **التمريرة تعمل
عند `display` فعّالًا فقط** (كما اليوم)؛ ولأن `readingComfort` يشترط `display`، فالطباعة
تعيش داخل هذه التمريرة نفسها — **مسار تنفيذ واحد، ومراقب DOM واحد، وتصنيف اتجاه واحد لا
يُشغَّل `detectDirection` مرتين**. هذا يزيل الحالات الخاصة الناتجة عن تشغيل الطباعة بلا
اتجاه عرض.

1. **اكتشاف الكتلة:** من `leafBlocks(root)` لكل جذر عرض مطابق للمحوّل (كما اليوم).
2. **فحص الحماية والاستثناء والفراغ:** `isProtectedElement` (كود/محرّرات/رياضيات) +
   `excludeSelector` للمحوّل + `isNumericTable` + تخطّي الكتل الفارغة. أي كتلة محمية/فارغة
   **تُتخطّى للاتجاه والطباعة معًا**.
3. **تصنيف الاتجاه (مرّة واحدة، للاتجاه وللطباعة):** دالة تصنيف واحدة
   `classifyRtl(block, mode, respectHostDir)` تُحسب **مرّة واحدة** لكل كتلة ويُعاد
   استخدام نتيجتها للاتجاه وللطباعة معًا:
   - `mode === 'rtl'` → `true`.
   - `mode === 'ltr'` → `false`.
   - `auto`: إن كان `respectHostDir && hasExplicitHostDir(block)` → حسب قيمة المضيف
     (`rtl`→true، `ltr`→false)؛ وإلا `detectDirection(block.textContent) === 'rtl'`
     (‏`null`/`ltr` → ليست RTL). يعيد استخدام [`detect.ts`](../src/core/detect.ts) بلا
     منطق جديد وبلا استدعاء مزدوج.
4. **تطبيق الاتجاه الحالي:** المنطق القائم في `applyToDisplay` دون تغيير: auto →
   `dir=auto` (أو إعادة للمضيف عند `respectHostDir`)، يدوي → `dir=mode`. (لا يوجد فرع
   «طباعة بلا اتجاه» — الطباعة تشترط `display` فعّالًا فتسير داخل هذا المسار.)
5. **تطبيق الطباعة (إن كانت الكتلة RTL و«راحة القراءة» فعّالة):**
   `setTypography(block, { fontSize, lineHeight })` — يلتقط اللقطة في الـ WeakMap ويكتب
   الأنماط السطرية. **لا سمة جديدة** (لا `data-sawb-rc`): الـ WeakMap `originals` هي
   مصدر الحالة، والعنصر يحمل أصلًا `data-sawb="display"` من ضبط الاتجاه. **شرط:** لا
   تُطبَّق على كتلة سُلِّمت للمضيف (فرع `respectHostDir` الذي يعيدها) — تلك تُتخطّى للطباعة
   أيضًا (لا نديرها).
6. **تحديث الطباعة عند تغيير الإعدادات:** تغيير `rcFontScale`/`rcLineHeight` يمرّ عبر
   `storage.onChanged` → `sync()` → `applyAll()`؛ `setTypography` يعيد الكتابة فقط إن
   اختلفت القيمة السطرية عن المطلوبة (idempotent) — بلا تكرار غير ضروري.
7. **إزالة الطباعة إن تحوّلت الكتلة إلى LTR:** في `onBatch`، إن أعيد تصنيف كتلة صارت
   غير RTL (بثّ غيّر نصها من عربي إلى إنجليزي)، يُستدعى `clearTypography(block)`: إن كان
   للعنصر لقطة في `originals`، يستعيد `font-size`/`line-height` الأصليين (يحذف الخاصية
   إن كانت غائبة أصلًا)، **دون المساس باتجاه الكتلة** (إن كان الاتجاه مطبَّقًا يبقى).
   الكشف عن «هل الطباعة مطبَّقة» يتم عبر مقارنة النمط السطري الحالي بالمطلوب/الأصلي من
   الـ WeakMap — **لا سمة مطلوبة**.
8. **الاستعادة عند التعطيل أو `stop()`:** `restoreAll` يستعيد كل عنصر يحمل `data-sawb`
   (‏`restoreElement` صار يستعيد حقول الطباعة أيضًا) إلى حالته الأصلية بايت-ببايت، ويزيل
   علامة `data-sawb`. لا علامة ثانية تُزال.
9. **كتلة يتغيّر نصها أثناء البث:** كل تحديث نصّي يولّد سجل طفرة → `onBatch` يعيد التصنيف
   والتطبيق على الكتلة المتأثرة فقط؛ idempotence يمنع الكتابة المكرّرة، فلا ارتجاج متكرّر.
   (إن تحوّل الاتجاه أثناء البث تُطبَّق الخطوة 7.)

## 6. اللقطة والاستعادة

### 6.1 توسيع `OriginalState`

في [`apply.ts`](../src/core/apply.ts)، تُضاف حقول الطباعة إلى البنية القائمة:

```ts
interface OriginalState {
  dir: string | null;
  styleDirection: string;
  styleUnicodeBidi: string;
  styleFontSize: string;     // جديد — قيمة font-size السطرية الأصلية ('' إن غابت)
  styleLineHeight: string;   // جديد — قيمة line-height السطرية الأصلية ('' إن غابت)
  hadStyleAttr: boolean;
}
```

- عند أول لمس لعنصر (سواء عبر `setDir` أو `setTypography`)، تُلتقط **كل** القيم السطرية
  الأصلية دفعةً واحدة (بما فيها `font-size`/`line-height`) — لقطة ذرّية تمنع استعادة جزئية.
- **حذف الخاصية بدل ترك قيمة فارغة:** عند الاستعادة، إن كانت القيمة الأصلية `''`
  (لم تكن سطرية) → `style.removeProperty('font-size')` / `removeProperty('line-height')`
  (لا تُترك `font-size: ''`). إن كانت غير فارغة → تُعاد كما هي.
- بعد الاستعادة، إن أصبحت `style.length === 0` و`!hadStyleAttr` → يُزال محدّد `style`
  بالكامل (المنطق القائم في `restoreElement`).

### 6.2 عدم إفساد استعادة `dir`/`unicode-bidi`

- **[حقيقة]** كتل العرض الورقية تتلقّى الاتجاه عبر **سمة `dir`** (لا `style.direction`)،
  والطباعة عبر **`style.font-size`/`line-height`**. فمسارا الاتجاه والطباعة لا يتصادمان
  على الخاصية نفسها.
- `restoreElement` يُوسَّع ليعيد `font-size`/`line-height` **إضافةً** إلى منطق `dir`
  الحالي، دون تغيير ترتيب استعادة `dir`/`direction`/`unicode-bidi`.
- `unicode-bidi: isolate` يُطبَّق فقط على العناصر التقنية السطرية (`code…`) وهي
  **ليست كتل RTL للطباعة**، فلا تتلقّى طباعة أصلًا — لا تعارض.

### 6.3 عنصر يغيّر الموقع طباعتَه بعده

- إن غيّر الموقع `font-size` الخاص به على كتلة بعد أن التقطتها صَوْب، تبقى اللقطة تحمل
  القيمة **الأصلية وقت أول لمس**. عند الاستعادة تُعاد تلك القيمة (كما هو سلوك `dir`
  اليوم تمامًا — موثّق في `restoreElement`). هذا سلوك مقبول ومتّسق مع المحرّك القائم.
- أثناء العمل، idempotence يعيد فرض قيمة صَوْب إن اختلفت — تمامًا كما يفعل `setDir`.

### 6.4 قرار الـ WeakMap: **مشاركة الخريطة الحالية (المصدر الوحيد للحالة)**

- **القرار:** الطباعة **تشارك** `originals` (WeakMap) الحالية في `apply.ts`، ولا تُنشئ
  خريطة مستقلة. الـ WeakMap هي **مصدر الحالة الوحيد** للطباعة — **لا سمة `data-sawb-rc`
  ولا أي سمة جديدة**.
- **التبرير:** العنصر نفسه؛ التقاط كل قيمه السطرية الأصلية في `OriginalState` واحد ذرّي
  يمنع تباعد لقطتين وازدواج ترتيب الاستعادة. خريطة ثانية تخاطر بلقطتين متضاربتين للعنصر
  نفسه واستعادة مزدوجة. الكشف عن «هل الطباعة مطبَّقة» يتم بمقارنة النمط السطري الحالي
  بالمطلوب/الأصلي المخزّن في الـ WeakMap — فلا داعي لعلامة إضافية.
- **الأثر على الملفات:** **جميع** دوال الطباعة (`setTypography`/`clearTypography`) تبقى
  **داخل [`apply.ts`](../src/core/apply.ts)** بجوار `snapshot`/`restore`/`setDir`، وتشارك
  `snapshot`/`originals` الخاصّين. **لا يُنشأ `src/core/typography.ts`** ولا أي ملف نواة
  جديد للطباعة.

## 7. القيم والنطاقات

**تمثيل داخلي آمن (نسبي لا مطلق):**

| القيمة | التمثيل الداخلي | كيف تتحقق في CSS | لماذا |
|---|---|---|---|
| حجم الخط | `rcFontScale: number` (مضاعف) | نسبة نسبية لحجم الموقع (مثل `font-size: 108%`) لا px مطلق | يحترم حجم الموقع الأساسي ويتجنّب الكسر عند تغيّر الموقع |
| تباعد الأسطر | `rcLineHeight: number` (معامل بلا وحدة) | `line-height: 1.8` (بلا وحدة) | يتناسب مع حجم الخط تلقائيًا؛ أكثر أمانًا من قيمة px |

**قيم البدء والنطاقات — «قيم بدء للاختبار الحي» لا أرقام نهائية:**

| المعامل | قيمة البدء | أدنى | أعلى | خطوة المنزلق |
|---|:---:|:---:|:---:|:---:|
| `rcFontScale` | **1.08** | 1.00 | 1.30 | 0.02 |
| `rcLineHeight` | **1.8** | 1.4 | 2.2 | 0.05 |

**لماذا نطاقات ضيّقة تمنع الكسر أكثر من نطاق واسع:**

- حجم أعلى بكثير (مثل ‏1.6×) يفيض البطاقات ثابتة الارتفاع، ويكسر محاذاة الجداول،
  ويحدث قفزات تمرير أثناء البث (القسم 11 من التشخيص).
- نطاق ‏1.00–1.30 يبقي التحسّن ملموسًا مع احتمال كسر ضئيل؛ تباعد ‏1.4–2.2 مريح دون
  تفكيك القوائم/الاقتباسات.
- **الأرقام النهائية تُثبَّت بعد التحقّق الحي** على المواقع الستة (القسم 12)، لا قبله.

> استخدام **نسبة/معامل** بدل px المطلق مقصود: يجعل الطباعة تتبع حجم الموقع الأصلي بدل
> فرض حجم ثابت قد يكسر تخطيطًا معيَّنًا.

## 8. تجربة الاستخدام

**لا تبويبات جديدة، لا عناصر خطوط.** التوسعة داخل الأقسام القائمة فقط.

### 8.1 قسم «راحة القراءة» في صفحة options

يُضاف ضمن قسم **«الإعدادات العامة»** القائم (لا قسم/تبويب جديد):

- **عنوان القسم:** `راحة القراءة`
- **وصف قصير:** `يحسّن حجم الخط وتباعد الأسطر للنص العربي المعروض — لا يغيّر النص ولا الإنجليزية.`
- **مفتاح تفعيل عام** (يضبط `Settings.readingComfort`):
  - التسمية: `تفعيل راحة القراءة`
  - وصف فرعي: `مطفأة افتراضيًا · تُطبَّق على الكتل العربية فقط`
- **منزلق حجم الخط** (`Settings.rcFontScale`):
  - التسمية: `حجم الخط`
  - القيمة المعروضة: نسبة مئوية مقروءة (مثل `‏108%`).
- **منزلق تباعد الأسطر** (`Settings.rcLineHeight`):
  - التسمية: `تباعد الأسطر`
  - القيمة المعروضة: المعامل (مثل `‏1.8`).
- **زر إعادة الافتراضيات:** `استعادة القيم الافتراضية` — يستدعي
  `setSettings({ readingComfort: false, rcFontScale: 1.08, rcLineHeight: 1.8 })`
  (أو `setSettings(DEFAULT_SETTINGS)` لكامل الإعدادات).
- **حالة التعطيل:** حين يكون المفتاح العام مطفأً، يظهر المنزلقان **معطّلَين بصريًا**
  (باهتين، `aria-disabled`) مع بقاء قيمتهما ظاهرة.

### 8.2 إدارة المواقع المعطّلة في options

ضمن قسم **«المواقع المحفوظة»** القائم (يعرض أصلًا `snapshot.sites`):

- **[حقيقة]** الشيفرة الحالية في [`options.ts`](../src/ui/options/options.ts) تعرض كل
  المواقع وتضع شارة `معطّلة` (`mode-disabled`) لِما `disabled=true`.
- التوسعة = **عرض/مرشّح للمواقع المعطّلة** + **زر «إعادة التفعيل»** لكل صف، يستدعي المسار
  القائم نفسه: إن لم تكن هناك قيم محفوظة أخرى `deleteSitePref(host)`، وإلا `saveSitePref`
  بإسقاط `disabled`. **بلا مخزن أو قائمة ثانية** (قرار 9).

### 8.3 المفتاح السريع في popup

- **[حقيقة]** الـ popup يحوي مفتاح `disable-toggle` (تعطيل الموقع) و`display-toggle`
  و`fields-toggle`، مبنية على `changeSetting`/`sendTemp`.
- يُضاف **مفتاح واحد**: `راحة القراءة` (per-site/temp)، يقلب طلب `readingComfort` للموقع
  الحالي عبر `changeSetting({ readingComfort: !cfg.readingComfort })` (يحفظ في `SitePref`
  إن كان «حفظ التفضيل» مفعّلًا، وإلا `TempOverride`) — نفس نمط `display-toggle` تمامًا.
- **اشتراط `display`:** بما أن `readingComfort` الفعّال يشترط `display=true`، فإن أثر
  المفتاح لا يظهر إلا حين تكون «النصوص المعروضة» مفعّلة. الاختيار الأبسط: إبقاء المفتاحين
  مستقلّين في العرض (كما اليوم)، على أن يعكس `cfg.readingComfort` القيمة **الفعّالة** بعد
  الاشتراط (فيظهر مطفأً تلقائيًا حين `display=false`). **لا يُغيَّر تصميم الـ popup** خلاف
  إضافة هذا المفتاح.
- **لا منزلقات حجم/تباعد في popup** (قرار 6). القيم من options فقط.

### 8.4 كيف يظهر أن الموقع مستثنى من راحة القراءة

- في popup: مفتاح «راحة القراءة» يظهر **مطفأً** (`aria-checked=false`) للموقع الحالي.
- الفرق البصري عن المنزلقين لا يلزم لأن القيم عامة؛ حالة الموقع تُقرأ من المفتاح فقط.

### 8.5 الفرق البصري: تعطيل الموقع كاملًا ≠ تعطيل راحة القراءة فقط

| الحالة | العنصر | اللون/الأيقونة | الأثر المرئي |
|---|---|---|---|
| تعطيل الموقع كاملًا | `disable-toggle` (أيقونة حظر، نحاسي) | نحاسي/`toggle-copper` | كل شيء يتوقف (اتجاه + طباعة) |
| تعطيل راحة القراءة فقط | مفتاح «راحة القراءة» | لون الوضع القائم (`--toggle-color`) | تُزال الطباعة فقط؛ الاتجاه يبقى |

هذان مفتاحان منفصلان بصريًّا ودلاليًّا، فلا يختلط «الموقع معطّل» بـ«راحة القراءة مطفأة».

### المرحلة 2 — منطق الطباعة (داخل apply.ts)
- **الملفات:** `core/apply.ts` **فقط** (لا ملف نواة جديد).
- **العمل:** توسيع `OriginalState`؛ `setTypography`/`clearTypography` (داخل `apply.ts`)؛
  توسيع `restoreElement`؛ `classifyRtl`؛ توسيع `applyToDisplay` بوسيط `typography` فقط.
  **لا سمة جديدة** — الـ WeakMap مصدر الحالة.
- **شروط القبول:** الطباعة تُطبَّق على كتل RTL فقط؛ استعادة حرفية؛ idempotence؛ لا تسرّب
  للإنجليزية/الكود/الحقول.
- **الاختبارات:** `tests/typography.spec.ts` (القسم 11)؛ `apply.spec.ts` يبقى ناجحًا.

### المرحلة 3 — دمج المحرّك
- **الملفات:** `core/engine.ts`.
- **العمل:** تمريرة العرض تبقى مبوّبة على `display` (لا بوابة `display || readingComfort`)؛
  تمرير `typography` إلى `applyToDisplay` حين `readingComfort` فعّال؛ ربط `onBatch`
  بإعادة التصنيف/الإزالة.
- **شروط القبول:** جدول الحقيقة (القسم 3) يتحقّق (بلا الحالة C)؛ البث وإعادة التصنيف يعملان.
- **الاختبارات:** توسيع `engine.spec.ts` (سيناريوهات RTL→LTR، تعطيل RC، stop).

### المرحلة 4 — التخزين والمراسلة
- **الملفات:** لا تعديل مصدر (تحقّق فقط).
- **العمل:** التأكّد أن `TempOverride` الموسّع يمرّ عبر `apply-temp` القائم، و`PageState`
  يحمل الحقول.
- **شروط القبول:** المفتاح السريع يصل للمحتوى ويطبّق فورًا؛ بيانات v1.1.0 القديمة تعمل.
- **الاختبارات:** اختبار «بيانات قديمة» + تدفّق الرسائل.

### المرحلة 5 — options
- **الملفات:** `ui/options/*`.
- **العمل:** قسم راحة القراءة (مفتاح + منزلقان + إعادة افتراضيات) + إدارة المواقع المعطّلة.
- **شروط القبول:** الحفظ في `storage.local`؛ حالة التعطيل البصرية؛ إعادة التفعيل بالمسار القائم.
- **الاختبارات:** توسيع `options.spec.ts`.

### المرحلة 6 — popup
- **الملفات:** `ui/popup/*`.
- **العمل:** مفتاح راحة القراءة السريع + `compactPref`.
- **شروط القبول:** يقلب `readingComfort` للموقع (حفظ/مؤقت) كنمط `display-toggle`.
- **الاختبارات:** توسيع `popup.spec.ts`.

### المرحلة 7 — الاختبارات
- **العمل:** استكمال كل اختبارات القسم 11.
- **شروط القبول:** كل الجديدة ناجحة + ‏219 القائمة ناجحة.

### المرحلة 8 — التحقّق الحي

## 11. خطة الاختبارات التفصيلية (اختبارات جديدة بالاسم والسيناريو)

في `tests/typography.spec.ts` (وتوسيعات في `engine`/`apply`/`options`/`popup`):

| الاسم المقترح | السيناريو | النتيجة المتوقّعة |
|---|---|---|
| `rtl block receives typography` | كتلة `<p>` عربية، `display` + RC فعّالان | `style.fontSize` و`line-height` مضبوطان (تحقّق من النمط السطري؛ **لا سمة**) |
| `ltr block untouched` | كتلة `<p>` إنجليزية، RC فعّالة | لا `font-size`/`line-height` |
| `code and fields unchanged` | `<pre><code>`، `<textarea>`، `<input>` | لا طباعة إطلاقًا (محمي/حقل) |
| `rc requires display` | `display=false` + RC مطلوب `true` | **لا طباعة** (‏`RC فعّال=false`، الصف A′) |
| `rtl→ltr restores typography only` | كتلة RTL تحمل طباعة يتحوّل نصها إلى إنجليزي | تُزال الطباعة؛ **الاتجاه يبقى** (كشف عبر النمط السطري/الـ WeakMap، لا سمة) |
| `size/line change updates without churn` | تغيير `rcFontScale`/`rcLineHeight` | الأنماط تُحدَّث؛ لا كتابة حين لا تتغيّر القيمة (idempotence) |
| `disable RC keeps direction` | RC→false مع بقاء `display` | الطباعة تُزال؛ اتجاه العرض يبقى (الحالة B) |
| `disable site restores both` | `SitePref.disabled=true` | `engine.stop()`؛ الاتجاه والطباعة يُستعادان |
| `stop restores everything` | `engine.stop()` مع طباعة نشطة | `innerHTML` يعود للأصل؛ لا `data-sawb` (لا علامة ثانية) |
| `original inline styles restored exactly` | كتلة عليها `style="font-size:20px"` أصلي | بعد الإطفاء تعود `20px` بدقة (لا حذف خاطئ) |
| `legacy v1.1.0 storage works` | تخزين بلا حقول RC | الافتراضيات تُملأ؛ `readingComfort=false`؛ لا خطأ |
| `popup saves correct RC state` | قلب المفتاح السريع (حفظ/مؤقت) | `SitePref.readingComfort` أو `TempOverride` صحيح |
| `options saves global RC values` | تحريك المنزلقين + المفتاح العام | `Settings.rcFontScale`/`rcLineHeight`/`readingComfort` محفوظة |
| `disabled sites management reactivates` | موقع `disabled=true` → إعادة تفعيل | يُحذف/يُحدَّث `SitePref` بالمسار القائم |
| `baseline stays green` | تشغيل الحزمة كاملة | **‏219 القائمة + الجديدة كلها ناجحة** |

## 12. خطة التحقّق الحي

على المواقع الستة الحالية: **ChatGPT · Claude · Gemini · Google AI Studio · GitHub ·
Substack**. لكل موقع، مع «راحة القراءة» مفعّلة (الحالة D) ثم مطفأة:

| السيناريو | ما يُراقَب |
|---|---|
| رد عربي | الطباعة على الفقرات العربية؛ لا كسر |
| رد مختلط عربي/إنجليزي | الطباعة على الكتل العربية فقط؛ الإنجليزية دون تغيير |
| بثّ مباشر للنص | لا ارتجاج متكرّر؛ الكتل الجديدة تتلقّى الطباعة؛ إعادة تصنيف عند تحوّل الاتجاه |
| قوائم | لا تشويه ترقيم/مسافات ضمن النطاق |
| اقتباسات (blockquote) | لا تضخّم حدود/هوامش مكسّر |
| جداول | لا كسر محاذاة أعمدة؛ الرقمي متروك |
| كود (inline + block) | لا طباعة إطلاقًا |
| تغيير الإعداد أثناء فتح الصفحة | تحديث فوري بلا إعادة تحميل، بلا وميض مزعج |
| تعطيل «راحة القراءة» للموقع | تُزال الطباعة فقط، الاتجاه يبقى (B) |
| تعطيل الموقع كاملًا | يُستعاد كل شيء (E) |
| إعادة التحميل | التفضيل المحفوظ يعود، المؤقت يزول |
| قفزات التمرير وارتجاج التخطيط | مراقبة CLS وقفزات موضع التمرير، خصوصًا أثناء البث والبطاقات ثابتة الارتفاع |

**مخرَج التحقّق:** تثبيت الأرقام النهائية لـ `rcFontScale`/`rcLineHeight` والنطاقات،
وتأكيد غياب موانع الشحن (القسم 13).

## 13. المخاطر وموانع الشحن (Blockers)

**أي بند من التالي = مانع شحن صريح لا يُتجاوز:**

1. **أي تعديل يمسّ النص الإنجليزي** (طباعة على كتلة غير RTL).
2. **أي تسرّب إلى الكود أو حقول الإدخال** (طباعة على `pre/code/kbd` أو `input/textarea`
   أو محرّر محمي).
3. **عدم استعادة الأنماط السطرية الأصلية بدقة** بعد الإطفاء/`stop()`.
4. **هبوط اختبارات خط الأساس عن ‏219** أو تغيير دلالة أيٍّ منها.
5. **فشل البناء** (`npm run build`).
6. **ارتجاج تخطيط واضح أثناء البث** على أيٍّ من المواقع الستة ضمن النطاقات المقترحة.
7. **تضخّم ملحوظ في كتابات DOM** (كتابة على كتل غير RTL، أو كتابة غير idempotent).
8. **تضارب بين تعطيل الموقع وتعطيل راحة القراءة** (خلط الحالتين E وB في جدول الحقيقة)،
   أو تشغيل طباعة مع `display=false` (الصف A′ يجب أن يُنتج «لا طباعة»).
9. **أي أثر للخطوط** (حقل، أصل، `web_accessible_resources`) — خارج النطاق كليًّا.

**قاعدة الشحن:** إن لم يُحسَم أي مانع أعلاه بنظافة مُثبَتة حيًّا، **لا يُشحن الإصدار**؛
يجوز تضييق النطاق (مثلًا تباعد فقط) لا توسيعه.

## 14. أمر التنفيذ اللاحق (يُعطى لاحقًا — لا يُنفَّذ الآن)

> **صيغة جاهزة لتسليمها إلى Sonnet 5 لاحقًا:**
>
> نفّذ ميزة «راحة القراءة» في مشروع SAWB وفق المواصفة المعتمدة `Draft 1.0` في
> `docs/sawb-reading-comfort-spec.md` حرفيًا، والقرارات النهائية الملزمة فيها. طبّق
> **حجم الخط وتباعد الأسطر على الكتل المصنّفة RTL فقط**، بالنهج (أ) (أنماط سطرية،
> بلا CSS variables على الجذر، بلا حقن ورقة أنماط، **بلا أي سمة جديدة — لا `data-sawb-rc`**)،
> مشاركةً `OriginalState`/`originals` WeakMap **داخل `apply.ts`** (‏**لا تُنشئ
> `core/typography.ts`**). **«راحة القراءة» تشترط `display=true`** (لا طباعة مع
> `display=false`؛ لا حالة C)؛ التمريرة تبقى مبوّبة على `display`. القيم **عامة**
> (`Settings.rcFontScale`/`rcLineHeight`)، وحالة التفعيل **يجوز أن تكون لكل موقع**
> (`SitePref.readingComfort`). الميزة **مطفأة افتراضيًا**؛ قيم البدء ‏1.08/‏1.8. أضِف
> مفتاحًا سريعًا في popup وقسمًا في options فقط، وإدارة المواقع المعطّلة عبر `SitePref`
> القائم. نفّذ المراحل ‏1→8 بالترتيب، وبين كل مرحلتين شغّل `npm run check` وتأكّد أن
> **‏219 اختبارًا تبقى ناجحة**. **ممنوع:** أي مساس بالنص الإنجليزي أو الكود أو حقول
> الإدخال، أي خطوط أو `web_accessible_resources`، أي وضع قراءة، أي موقع جديد، أي إعادة
> بناء، أو أي توسيع للصلاحيات. احترم موانع الشحن في القسم 13. لا تبدأ Font Feasibility Spike.
